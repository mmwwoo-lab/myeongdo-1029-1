> **기획·시읽기:** 명도재 이명우 | **매뉴얼 버전:** 1.0 (2026-10-30)
> **표본 웹사이트:** https://mmwwoo-lab.github.io/myeongdo-1029-1/seongdoo/

## A. 목적과 원칙
시인에게서 **시집 제목·시인 이름·복수의 시 원문**을 받으면, 원문 보존 → 차례·부 구성 → 1편당 시 페이지와 '이명우 시읽기' 평론 페이지 → 낭송 기능 → 앞뒤표지와 삽화 → 웹시집 검수·배포까지 일괄 제작하는 **재사용 가능한 디지털 시집 표준**이다.

**필수 원칙:** 시의 어휘, 행갈이와 연 구분은 승인 없이 임의 변경하지 않는다. 맞춤법·지명·인명 수정은 별도 교정안으로 제시하고 승인 뒤 반영한다. 원문 게재·번안·낭송·공개에 대한 시인/권리자 이용 허락을 먼저 확인한다. '이명우 시읽기'는 시인 본인의 해설로 오인되지 않도록 별도 표시한다. 인용과 평론은 원문의 구체적 시어에 근거한다.

## B. 표본 1에서 확인된 요소
- **시집:** 『별꽃은 피고 지고』 / **시인:** 이성두 / **시읽기:** 이명우
- **총 98편, 4부:** 1부 분홍 옹알이(23), 2부 달맞이꽃 피는 밤에(21), 3부 돌아보는 쪽(27), 4부 작은 불씨(27).
- **표본 파일:** `index.html`(표지, 목차, 책장, CSS), `reader.js`(페이지 구성·이동·낭송), `poems.json`(시 원문·기본 해설), `reading-part1.json`~`reading-part4.json`(보강 시읽기).
- **현재 낭송 방식:** 브라우저 `speechSynthesis`의 한국어 음성합성(TTS). 별도의 MP3·WAV 파일을 만들거나 저장하는 구현이 아니다. 운영체제·브라우저의 음성 제공 여부에 좌우된다.
- **표지:** 짙은 녹색 질감, 이중 금빛 테두리·모서리 장식, 짙은 황금색 손글씨 제목. 앞·뒤표지 형식 통일.
- **읽기 방식:** 데스크톱 양면 책, 모바일 한 면. 책의 좌우 화살표·키보드로 넘김. 상단 목차는 우측 책 면 위에 겹쳐 표시하고 바깥을 클릭하면 닫힘. 하단 이동 버튼 영역 없음. 화면 중앙 낭송 일시정지 표시 숨김.
- **원고/시읽기 배열:** 시 한 페이지 다음에 해당 작품의 '이명우 시읽기' 한 페이지. 부 도입에는 삽화·부 소개·부별 목차를 제공.
- **편집 기준:** 긴 시는 연 경계를 우선하여 2단으로 나누고 자동 글자 축소로 하단 넘침을 완화. 일부 후반 페이지에 행간 1.12 설정이 존재하나, **이를 전체 시집의 획일적 기준으로 복제하지 말고 실제 화면으로 검수한다.**

## C. 의뢰 접수 양식
```text
[시집 기본정보]
시집 제목:
시인명(표기·한자·영문 선택):
시인 약력(선택):
시 수 / 부 구성: (미지정 시 제안 가능)
시집 서문·발문(선택):
표지 이미지·색·서체 선호:
낭송 음색·성별·속도 선호:
저작권자와 웹공개·TTS·음원제작 허락 여부:
원고 최종본 확정일:

[각 시]
번호:
시 제목:
부 번호:
시 원문(줄바꿈과 빈 줄 그대로):
```

원고는 UTF-8 텍스트, DOCX 또는 표 형태로 받아도 되나 `poems.json`에는 **시 제목/부 번호/원문의 개행을 정확히 보존**해 등록한다. 제목 중복을 허용하되 번호 `n`은 고유해야 한다.

## D. 제작 공정 — 12단계
1. **권리 및 원고 확인:** 시인, 제목, 작품 수, 권리 허락, 미발표 여부 확인.
2. **원문 정리:** 번호 부여, 띄어쓰기·행갈이·연 구분 보존, 중복·누락 검출. 교정 후보는 승인 별도.
3. **부 구성:** 작가 의도에 따라 부 제목과 작품 순서 확정. 부 소개(2~3문장) 작성.
4. **메타데이터 작성:** `poems.json`의 `title`, `author`, `critic`, `parts`, `poems` 채움.
5. **평론 작성:** 작품별 '이명우 시읽기'를 400~500자 정도로 시작하되 **페이지 채움 70% 목표를 우선**하여 실제 서체/화면에 맞춰 조정. 단순 상투적인 문단 반복 지양.
6. **평론 검수:** 시의 실제 구절 1~2개, 시상 전개, 이미지·시어·리듬, 주제의 확장, 평론자의 독서 관점, 종결의 여운을 근거로 다듬기. 작품과 무관한 해석·경력·사연을 만들지 않기.
7. **디자인:** 표본 1 앞뒤표지의 금빛 장식과 짙은 녹색을 기준으로 시인·책 제목만 교체. 저자 표기, 저작권 고지, 접근성 대비 확인.
8. **본문 조판:** 1편 1시 페이지를 우선. 긴 시는 왼쪽에서 오른쪽으로 이어지는 2단. 연 경계를 우선하고 원문에 없는 빈 줄을 만들지 않기. 난도가 높은 긴 시는 별도 편집안/페이지 분할 검토.
9. **낭송 원고:** 원문 시·해설을 별도로 구분. 낭송에서 제목·시인명과 쉬는 호흡을 정확히 다듬되 화면상의 원문은 수정하지 않기.
10. **오디오:** 기본은 웹브라우저 TTS. **실제 오디오 파일이 필요하면** 동의를 받은 한국어 TTS 서비스로 음원을 생성하고 편당 시 낭송/해설 파일을 각각 확보, 음량·발음·끝부분 끊김을 점검하여 MP3 등으로 저장. 저장형 오디오는 별도 제작·연결 개발이 필요하며 현재 표본에는 구현되지 않음.
11. **기능검수:** 첫·끝페이지, 4부 전환, 목차 선택과 바깥 클릭 닫힘, 좌우 버튼, 모바일 반응형, TTS 지원·비지원 환경, 오버플로우·겹침, 브라우저 콘솔 오류 확인.
12. **배포와 공유:** 기존 책 폴더와 분리된 새 폴더를 GitHub에 커밋 → GitHub Pages/배포 설정 확인 → 공개 HTTPS 링크 실제 접속·페이스북 미리보기·오디오 모바일 재생 테스트. 링크와 변경 기록을 전달.

## E. '이명우 시읽기' 집필 규격
**문체:** 이명우의 독서·미술적 시각, 따뜻하지만 비평적이며 근거 중심의 서술. 1인칭 '나는 이 시에서…'은 필요한 경우만 자연스럽게. 기계적 동일 문장 반복 금지.
**구성 권장:** (1) 핵심 장면의 직접 관찰, (2) 주제와 화자의 정서·시간, (3) 이미지와 수사·전환·연 구성 분석, (4) 독자와 연결되는 미학적 의미 및 작품의 여운. 2~3문단.
**검증:** 원문에 없는 구절을 따옴표로 만들지 않으며 사실과 해석을 구분. **글자 수와 페이지 점유율은 다른 기준**이므로 목표 분량(예: 400~550자)은 70% 페이지 점유율에 맞추어 조정한다. 현재 표본의 별도 시읽기 JSON은 약 400~500자 범위이나, 실제 70%는 최종 렌더링을 확인해야 한다.

## F. 데이터 구조와 파일명
```json
{
  "title": "새 시집 제목",
  "author": "시인명",
  "critic": "이명우 시읽기",
  "parts": ["제1부 제목", "제2부 제목"],
  "poems": [
    {
      "n": 1,
      "title": "시 제목",
      "part": 1,
      "text": "첫 행\n둘째 행\n\n다음 연 첫 행",
      "commentary": "작품별 시읽기 원고"
    }
  ]
}
```
**주의:** 표본의 `reader.js`는 별도 `reading-part1.json`~`reading-part4.json`을 불러오도록 설계되어 있다. 부 수가 바뀌는 신규 시집은 반드시 해당 불러오기 코드·JSON 파일 수를 일치시키거나 **부 수를 자동 인식하는 코드로 개선**해야 한다. 별도 해설 파일의 `n`과 `part`가 시 원문과 정확히 일치해야 한다.

**신규 폴더 권장 구조**
```text
new-poetry-book/
  index.html
  reader.js
  poems.json
  reading-part1.json  # 부별 추가
  assets/
    cover/             # 선택
    audio/             # 저장형 MP3 제작 시에만
  README.md
```

## H. 최종 출판 승인 체크리스트
- [ ] 작품 번호·제목·부·98편 같은 총 편수 집계가 일치한다.
- [ ] 행·연·구두점·고유명사는 승인된 원고와 대조했다.
- [ ] 한 작품의 시와 평론이 짝을 이루고, 읽기 목소리가 구별된다.
- [ ] 모든 시/시읽기 페이지의 상하좌우 겹침·넘침을 **데스크톱과 모바일 실제 브라우저**에서 확인했다.
- [ ] 축소된 글자가 너무 작지 않고 책장의 시선 흐름이 자연스럽다.
- [ ] 목차·페이지 넘김·TTS 시작/일시정지·재생 중 페이지 변경을 점검했다.
- [ ] 금박 표지 및 뒤표지, 시인명, 서문, 저작권 표기, SNS 공유 이미지가 정상이다.
- [ ] 음성 TTS와 **저장 가능한 오디오 파일 제작**을 혼동하지 않았다.
- [ ] 공개 링크 HTTPS·브라우저·페이스북 공유 미리보기를 확인했다.
