# 명도재 생활수필 표준 원고·편집·출판 작업 양식
**관리 책임:** 비서실장 · **적용:** 제1~18편의 편집 기준을 참고한 이후 모든 신규 작품과 요청된 개정본 · **저자:** 명도재 이명우

> **운영 원칙:** 실제 부서를 별도로 운영한다고 주장하는 것이 아니라, 비서실장이 총괄하는 독립 작업·검토 역할을 정의한다. 실제 수행·확인한 결과만 '완료'로 보고한다. 작가가 요청하지 않은 기존 작품 원문 변경은 금지한다.

## A. 작품 접수 카드 — 소재·기록조사팀 작성

| 필드 | 표준 입력 |
|---|---|
| 작품 번호 | 제__편 (기존 번호 확인 후 배정, 중복 금지) |
| 작품 제목 | (가급적 5~15자, 작품 내용이 우선) |
| 부제 | (필요할 때만) |
| 저자 | 글 \| 명도재 이명우 |
| 집필 날짜와 장소 | 제공된 사실만 기록; 없으면 '미확인' |
| 소재 영역 | 일상 / 가족 / 자연 / 회상 / 사회·문화 / 예술·AI / 여행·만남 / 삶의 철학 |
| 중심 장면 | 독자가 눈앞에 그릴 수 있는 실제 사건 1개 |
| 보조 장면 | 최대 2~3개; 실제 경험·기억과 구분 |
| 등장인물·대화 | 원문 인용 / 기억에 따른 재구성 / 확인 필요를 구분 |
| 감각 기록 | 장소, 빛, 소리, 냄새, 표정, 움직임 |
| 핵심 정서 | 그리움·유머·감사·성찰 등 |
| 사실·출처 검토 | 실명·행사·수상·날짜·공적 주장 확인 여부 |
| 작가 지시 | 분량, 페이지 수, 이미지, 낭독, 배포 범위 |
| 변경 범위 | 신규 창작 / 일부 윤문 / 전체 재창작 / 편집만 / 삽화만 |

## B. 표준 출판 원고

```text
명도재 이명우의 생활수필 · 제00편

[제목]
― [부제: 필요한 경우]

글 | 명도재 이명우

[도입: 실제 장면과 관찰 150~250자]

[전개: 중심 사건·대화·행동 400~600자]

[심화: 감정의 움직임·회상 400~600자]

[성찰: 삶과 관계의 의미 250~400자]

[결말: 첫 이미지 또는 감각을 회수하는 여운 100~200자]

[확인된 날짜와 장소]
```

**집필 기준:** 1인칭 생활서사형 서정수필. 권장 1,300~2,000자; 실제 사건이 풍부하거나 작가가 지정하면 그 이상. 위 구성의 단계명은 **작업용**이며 완성 수필 본문에는 인쇄하지 않는다. 한 문단에는 주요 장면 또는 감정 한 가지를 중심으로 자연스러운 산문을 쓴다. 문장과 단락을 무리하게 단축해도 내용·맥락을 잃지 않도록 한다.

**사실성:** 실제 인물의 발언을 임의 창작해 실화로 제시하지 않는다. 외부 사상·정치·건강·법률에 관한 단정은 사실과 개인 의견을 구별한다. 상담·미술교육에서 그림 하나로 사람의 심리를 판정하지 않는다.

## C. 기존 책장형·신문형 표준 디자인

| 항목 | 전편 공통 기준 |
|---|---|
| 원고 표시 | 제00편 → 제목 → 부제(선택) → 저자 → 본문 → 확인된 날짜·장소 |
| 제목·본문 | 기존 책장형과 일치하는 글꼴 위계, 한국어 가독성 우선 |
| PC 페이지 좌우 여백 | 제17편 기준 `clamp(73px, 6.5vw, 98px)` |
| 모바일 페이지 좌우 여백 | 제17편 기준 `clamp(47px, 10vw, 65px)` |
| 문단 구분 | 첫 줄 억지 줄바꿈 금지. 문단 아래 PC 5px, 모바일 4px; 위쪽 0 |
| 문장 배치 | 양쪽 정렬, 한국어 단어 단위 줄바꿈, 대화 상대가 바뀌면 문단 구분 |
| 그림 | 첫 장 삽화 원칙, 가로 16:9 권장, 작품별 장면과 일치, 문장 가리지 않기 |
| 페이지 수 | 작가 지정 우선, 가능하면 짝수 쪽. 글자 잘림보다 한 장 추가를 우선 |
| 페이지 넘김 | 문단 경계 우선, 시작·끝 문맥 연결, 다음 장에 중복/누락 없음 |
| 오디오 | 기존 읽기·일시정지·이어 읽기·정지 동작과 한국어 발음 확인 |
| 출판본 | 책장형·신문형 원고 동일. 목차·번호·삽화·링크·오디오 동기화 |

**매우 중요:** 서체와 줄 간격, 지면 폭을 작품마다 임의로 변경하지 않는다. 좁은 화면에서 인용문, 제목, 삽화 때문에 본문이 잘리면 보이지 않게 숨기는 대신 페이지 재분할 또는 적정 글자 조절을 우선한다.

## D. 업무부서 책임 분장 — 각 공정의 최종 책임자 단일 지정

| 단계 | 업무 책임 부서 | 담당할 일 | 납품 결과 |
|---|---|---|---|
| 0 | 비서실장 | 번호·원고 종류·요청 범위·담당자·완료 기준 확정 | 작업지시서 |
| 1 | 소재·기록조사팀 | 원본 보존, 장면·사실·인물·직접인용 정리 | 접수 카드 + 사실 확인표 |
| 2 | 문학창작팀 | 장면→사건→감정→성찰→여운으로 초안 집필 | 창작 원고 제1고 |
| 3 | 문학평론·퇴고팀 | 중심 이미지, 서사 연결, 반복, 비유, 결말 검토 | 편집 의견 + 제2고 |
| 4 | 전문자문팀(조건부) | 아동·미술심리·상담·교육·의학·법률·사회 주장 검토 | 사실·윤리 검토표 |
| 5 | 교정·교열팀 | 맞춤법, 시제, 사투리, 호칭, 인용, 문장 호흡 최종 교정 | 교정 완료 원고 |
| 6 | 조판·편집팀 | 통일 여백·글자·문단·쪽수, 문장 미절단, 이어짐 검토 | 페이지별 조판본 |
| 7 | 디자인·삽화팀 | 원고 대표 장면 선택, 기존 책과 통일된 작품 이미지 제작·배치 | 삽화 + 이미지 설명 |
| 8 | 기술·오디오팀 | 책장형/신문형 연결, 목차·낭독·모바일·이미지 경로 테스트 | 기능 검수표 |
| 9 | 출판·배포팀 | 원고·이미지 버전 확인 후 반영, 캐시 갱신, 공개 URL 점검 | 커밋·발행 이력 |
| 10 | 최종 검수팀 | 원고 대조·문단 연속성·시각적 완전성·기능 결과 확인 | 최종 검수 보고 |
| 11 | 비서실장 | 모든 결과 취합, 반려/수정지시/승인, 작가에게 보고 | 최종 편집·출판 보고 |

**부서 업무 충돌 방지:** 문학창작팀은 디자인 규격을 이유로 사실이나 장면을 임의 삭제하지 않는다. 디자인팀은 문학창작팀의 원고를 마음대로 수정하지 않는다. 기술팀은 편집팀의 승인 없이 누락을 감추려고 본문에 `overflow:hidden`만 추가하지 않는다. 보고는 비서실장에게 모이고 최종 원고 결정권은 작가의 요구사항을 따르는 비서실장에게 있다.

## E. 비서실장 협업 판단표 — 필요할 때 즉시 공동 작업 지시

| 발견된 상황 | 협업을 지시받을 부서 | 비서실장 결정 및 확인 |
|---|---|---|
| 실제 대화·날짜·장소에 불확실성이 있음 | 기록조사 + 창작 + 교정 | 확인되지 않은 내용을 단정하지 않고 원고에 반영 |
| 심리·가족·교육적 해석이 포함됨 | 문학창작 + 전문자문 + 평론 | 과학적 진단처럼 보이는 단정 삭제 |
| 원고가 너무 길거나 페이지가 남음 | 문학창작 + 조판 + 디자인 | 독자 가독성과 원문 보존을 우선해 페이지 재분배 |
| 첫 페이지 제목·삽화 때문에 본문이 밀림 | 디자인 + 조판 + 기술 | 책 공통 여백 유지, 삽화 크기 조정, 실제 화면 검수 |
| 새 이미지가 기존 작품과 화풍이 달라짐 | 디자인 + 문학평론 | 장면 적합성과 화풍 통일 검수, 작가 요구 우선 |
| TTS가 끊기거나 이어 읽기 실패 | 기술·오디오 + 조판 + 검수 | 재현 조건 기록, 고친 후 재시험 |
| 신문형과 책장형 내용 불일치 | 교정 + 기술 + 출판 | 같은 원본으로 재연결 후 전체 대조 |
| 권리·개인정보·인용 문제 | 기록조사 + 전문자문 + 출판 | 공개 전 출처·동의·사용 범위 확인 |
| 기존 수필의 개정 요청 | 비서실장 + 해당 부분 책임부서 | 지정된 작품과 수정 범위만 처리 |

**협업의 승인 경로:** 담당 부서 문제 접수 → 비서실장 우선순위·관계 부서 결정 → 부서별 독립 점검 → 공동 해결안 1개 제시 → 최종 검수 → 비서실장 승인·보고. 전문가를 실제로 섭외하지 않은 경우에는 '전문가 검토 완료'라고 표현하지 않는다.

## F. 공정별 검수 기준과 통과 조건

| 검수 단계 | 필수 확인 | 미통과 시 |
|---|---|---|
| 문학 검수 | 실제 중심 장면, 작가의 목소리, 서사의 연결과 결말 여운 | 창작팀으로 반려 |
| 사실·윤리 검수 | 실재 인물·직접인용·상담/교육적 주장 사실성 | 기록조사/자문으로 반려 |
| 편집 검수 | 원고 누락 0, 문장 중복 0, 작품·쪽 번호 정확, 문단 경계 자연스러움 | 조판팀 재배치 |
| 디자인 검수 | 첫 장 삽화 적절, 전체 여백 규격, 모바일 제목·본문 가독성 | 디자인팀 조정 |
| 기술 검수 | 목차 연결, 책장 넘김, 신문형 본문, TTS, 이미지, 주소 작동 | 기술팀 수정 후 재시험 |
| 출판 검수 | 기존 작품 보존, 변경 파일 목록, 버전·링크 검증 | 발행 보류 또는 제약 명시 |

**품질 자체 점검:** 관찰/소재 20, 구성/연결 20, 문장력 20, 진정성 20, 성찰/여운 20의 **100점 참고 점검표** 사용. 점수는 작업 개선 목적이며 객관적 문학 평가로 가장하지 않는다.

문학팀: [수행 내용·문장 개선]

## H. 보존·개정 관리

1. 기본 서식과 분업·협업 규칙을 이후 작품에 자동 적용한다. 작품별 별도 지시가 있으면 작가의 명시적 요구를 우선한다.
2. 제1~18편은 현재 공개 원고와 편집본을 보존하며 개별 수정 지시 없이 일괄 재창작하거나 기존 데이터를 삭제하지 않는다.
3. 원고 내용 변경과 단순 디자인 변경을 엄격히 구분하여 이력을 남긴다.
4. 실제 수행하지 않은 기기 테스트, 독립 전문가 검토, 출판 배포를 완료했다고 보고하지 않는다.
