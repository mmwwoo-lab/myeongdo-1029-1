# 명도재 이명우의 오늘의 수필

이 디렉터리는 매일 쓰는 수필을 기존 생활수필집과 구분해 보관하는 독립 연재 공간입니다.

- `index.html`: 책장 넘기기·오디오 낭독이 있는 수필집
- `YYYY-MM-DD.md`: 날짜별 원고와 자료 출처

제1권 《삶이 남겨 둔 의자》는 100쪽 완성본입니다. 2026-11-23 정식 수필 1편과 기존 생활수필 창작 편집본 22편을 재수록했습니다. 표지 1쪽, 머리말 1쪽, 목차 2쪽, 본문 95쪽, 자료 1쪽으로 구성합니다. 날짜별 신작은 별도 원고로 계속 보관합니다. 검증된 글만 인용하고, AI 교육 이야기는 신종우 교수의 공개 칼럼과 확인된 자료를 먼저 살펴봅니다.

편집 분장: 비서실장(전체 일정·최종 확인), 자료 담당(원문·날짜·출처), 집필 담당(수필), 교열 담당(표현·정치 소재 제외), 제작 담당(책자·오디오·공개 상태).

참고 인물: 강종래 화가의 공개 인터뷰·작가 본인 글, Sangguk Oh님과 김쌍주님의 공개 페이스북 글. 작가 본인이 쓴 글과 기자의 인터뷰 기사를 구분하고, 게시글의 작성자·날짜·원문을 확인할 때만 인용합니다. Sangguk Oh님의 프로필 주소만으로는 게시글 내용이나 본명을 추정하지 않습니다. 김쌍주 기자의 공개 기사와 사용자 지정 김쌍주 페이스북 친구는 동일인임을 확인하기 전에는 연결하지 않습니다.

추가 참고 친구: 박계현(https://www.facebook.com/colordaejin), 이향숙(https://www.facebook.com/ihyangsug.136737), 박태성(프로필 미확인). 페이스북 원문과 날짜가 확인되지 않은 글은 인용하지 않으며, 박태성을 검색되는 동명이인 저자와 연결하지 않습니다.


## 비서실장 지시서 · 2026년 11월 23일 예시 수필

오늘의 예시 원고: [〈안부 한 줄이 새 교실이 되는 날〉](examples/2026-11-23.md). 날짜별 본편 `2026-11-23.md`와 별도 보관합니다.

| 담당 | 오늘의 업무 | 확인 기준 |
| --- | --- | --- |
| 비서실장·총괄 편집 | 제목·날짜·작성 범위 확정, 담당별 결과 취합 | 예시 작품임을 표시하고 본편과 혼동하지 않음 |
| 자료 조사·출처 | 강종래 인터뷰, 신종우 칼럼 원문과 날짜 대조; 페이스북 후보글 확인 | 검증되지 않은 게시글과 인용은 사용하지 않음 |
| 수필 집필 | 교직 36년·퇴직 후 미술·문학·AI 교육을 일상 풍경과 연결 | 사실·관찰·해석을 구분해 명도재 시점으로 씀 |
| 교열·윤리 | 문장 흐름, 이름 표기, 정치 소재와 과도한 전재 점검 | 원문 짧게 인용하거나 재서술, 정치 내용 제외 |
| 책자·오디오 제작 | 승인된 본편만 책자에 누적, 페이지·읽기 버튼 확인 | 예시는 별도 보관; 제1권 100쪽과 예시 원고 분리 |
| 공개 검증 | 저장소의 파일과 링크 확인, 웹 공개 접속 검사 | 확인된 저장과 확인 못 한 웹 배포를 구분해 보고 |

보고: 예시 원고는 저장소에 저장했습니다. 추천 친구의 최근 페이스북 글은 확인되지 않아 인용하지 않았습니다. 웹 공개 주소 접속 여부는 별도로 확인이 필요합니다.

## 100쪽 책자 편집 원칙

- 기존 22편은 이전 명도재 생활수필집의 창작 편집본을 재수록합니다. 새로 쓴 오늘의 수필과 목차에서 구분합니다.
- 정치인의 이야기가 포함된 기존 문단은 이 판에서 제외했습니다.
- 새로 쓰는 날짜별 원고는 별도 파일로 추가하고, 제1권 100쪽은 완결 판으로 보존합니다. 다음 신작은 별도 권으로 이어 엮습니다.
- 책자 오디오는 브라우저의 한국어 음성 합성 기능을 사용하며 기기 환경에 따라 지원 상태가 다릅니다.
