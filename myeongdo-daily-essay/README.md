# 명도재 이명우의 오늘의 수필

이 디렉터리는 매일 쓰는 수필을 기존 생활수필집과 구분해 보관하는 독립 연재 공간입니다.

- `index.html`: 책장 넘기기·오디오 낭독이 있는 수필집
- `YYYY-MM-DD.md`: 날짜별 원고와 자료 출처

2026-11-23 첫 편 〈빈 의자를 향해 다시 말을 건네다〉 수록. 목표는 50쪽이며 현재 책자 12쪽입니다. 검증된 글만 인용하고, AI 교육 이야기는 신종우 교수의 공개 칼럼과 확인된 자료를 먼저 살펴봅니다.
