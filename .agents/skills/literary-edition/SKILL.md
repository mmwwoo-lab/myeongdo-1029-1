# 시집 및 생활수필집
- 대상: poetry-book/와 essay-book/. 다른 문학관 디렉터리도 먼저 구조 확인.
- 신규 작품의 원본과 승인 여부가 확인된 경우에만 추가한다.
- 저자, 제목, 시의 행갈이·연 구분, 수필 문단을 임의로 고치지 않는다.
- 원본과 렌더링 파일의 역할을 분리하고 기존 작품 URL을 유지한다.
- 목차 이동, 기존 작품 접근, 스마트폰 폰트와 페이지 분할을 점검한다.
- 음성은 HTML TTS 또는 실제 MP3인지 명확히 구별한다.
- 모든 변경은 별도 브랜치에 제한하고 발행인 승인 없이 배포하지 않는다.
