# 승인과 공개 배포
1. PR diff와 변경 파일 목록, 기존 문학 원문 및 URL 영향 여부를 보고한다.
2. 기사 출처와 날짜, 이미지 권리, 정적 경로 검사, 음성/모바일 수동 검수 결과를 구분한다.
3. 발행인 검토를 위해 Draft Pull Request를 우선 사용한다.
4. PR의 생성은 승인 요청이며 main 병합이나 실제 외부 배포를 뜻하지 않는다.
5. 사용자가 구체적으로 배포/병합을 승인한 뒤에만 운영 브랜치에 반영한다.
6. 배포 후 공개 URL, 실제 접근 상태, 미해결 항목을 점검한다.
