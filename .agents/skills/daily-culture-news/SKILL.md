# 대구 문화예술신문 초안 제작
1. 대상 날짜와 시간대(Asia/Seoul)를 확인한다.
2. 취재 가능 기관·언론·공식 공고의 출처 URL, 게시일, 행사일/장소를 구분해 기록한다.
3. 기존 기사의 제목·주제를 대조하여 중복을 피한다.
4. 최대 4건을 자체 문장으로 작성한다. 검증되지 않은 사건은 보류하고 기사 수를 억지로 채우지 않는다.
5. 출처가 없는 문장, 허구 인용, 외부 사진/기사의 무단 복제를 허용하지 않는다.
6. JSON 초안은 content/drafts/YYYY-MM-DD.json 에 저장한다.
7. python scripts/validate_issue.py --dir content/drafts 를 실행한다. 이 검사는 진위 판정이 아니라 형식 검사다.
8. SNS 소개문은 초안으로만 작성한다. 자동 SNS 게시와 사이트 공개는 금지한다.
9. 완료 보고에 기사 제목, 출처, 미확인 사항, 승인 요청을 포함한다.
