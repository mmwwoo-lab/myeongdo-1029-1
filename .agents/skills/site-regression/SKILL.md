# 홈페이지 회귀검사
1. index.html, poetry-book/index.html, essay-book/index.html 및 기존 배포 workflow를 확인한다.
2. 내부 이미지/링크 경로에 대해 scripts/check_site.py를 실행하고 문제를 분류한다.
3. 375px·768px·1440px 화면에서 글자 겹침·가로스크롤·목차 동작을 실제 브라우저로 점검한다(도구 가능 시).
4. 낭송 버튼의 클릭 → 재생 → 일시정지 → 이어읽기 동작은 실제 브라우저에서 추가 검사한다.
5. 메타 태그 OG 이미지는 공개 URL과 존재 여부를 별도로 확인한다.
6. 정적 스크립트 결과만으로 소리 출력, 모바일 호환성, Facebook 미리보기까지 성공했다고 보고하지 않는다.
7. 발견 오류는 최소 수정 작업 브랜치에서 처리하고 운영 반영은 승인받는다.
