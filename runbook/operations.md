## 주의 사항

- Vercel 배포는 GitHub와 자동 연결된다고 가정하지 않는다.
- GitHub Actions의 품질 검사만으로 AI 기사 생성이나 예약 발행은 이루어지지 않는다.
- Codex 자동화, GitHub Actions schedule, 별도 서버 중 실제 운영 환경을 확인한 뒤 일정을 설정한다.
