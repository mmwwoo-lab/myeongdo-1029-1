# 물빛에 놓아둔 마음 — 명도재 이명우 창작 시집

기존 홈페이지와 독립된 정적 시집입니다. 저장소 루트에서 `python3 -m http.server 4174 --bind 127.0.0.1`로 실행한 후 `/poetry-book/` 경로를 엽니다. 별도 빌드나 패키지 설치는 필요 없습니다.

- 창작시 38편의 제목과 원문을 기존 홈페이지에서 보존했습니다.
- 시집 제목: 『물빛에 놓아둔 마음』 / 부제: 기억을 건너, 계절을 지나.
- 4부 구성: 어머니의 시간(12편), 꽃이 머무는 계절(7편), 저녁을 건너는 사람들(8편), 물이 기억하는 풍경(11편).
- 편집의 말, 전체 차례, 각 부의 작품별 차례와 시화 삽화를 추가한 디지털 판입니다. 화면 크기와 실제 본문 높이에 맞춰 지면을 나누므로 쪽수는 기기에 따라 달라집니다. 부별 여는 글은 시 원문과 구분한 편집 문구입니다.
- 두 번째 지면에 제공 영상 「물에게 길을 묻다」(H.264/AAC, 약 3분 47초)를 포함했습니다.
- 데스크톱 양면, 모바일 단면, 좌우 버튼·키보드·스와이프·목차 이동을 지원합니다.
- 왼쪽 책장을 클릭하면 이전, 오른쪽 책장을 클릭하면 다음으로 넘깁니다. 모바일은 단면의 왼쪽/오른쪽 절반을 사용합니다. 영상·목차 버튼·선택한 텍스트는 페이지 클릭 넘김에서 제외합니다.
- 책장을 넘길 때 Web Audio로 짧은 클릭음과 종이 넘김 소리를 재생합니다. 상단의 소리 켜기/끄기는 브라우저에 기억됩니다. 자동 재생하지 않으며 음원 다운로드가 필요하지 않습니다.
- 실제 내용과 쪽수를 담은 불투명한 앞·뒷면이 회전하며, 다음 지면이 아래에서 드러납니다.
- 짙은 회색 배경과 밝은 종이를 사용하고, 기존 책의 가로·세로를 90%로 줄였습니다.
- 각 작품은 기본 1페이지, 긴 시도 최대 2페이지로 구성합니다. 본문은 페이지 안의 2단을 왼쪽부터 오른쪽 순서로 읽습니다. 실제 화면에 맞춰 글자 크기와 행 배치를 측정하며 원문의 행과 연 구분을 보존합니다.
- 동작 줄이기 설정을 존중하며 자동 재생하지 않습니다.

배포할 때는 이 폴더 전체를 사용하세요. 표지와 영상까지 폴더 안에 포함되어 있으므로 상위 홈페이지 파일은 필요하지 않습니다. 기존 사이트와 함께 배포하면 `/poetry-book/`가 시집의 독립 주소가 됩니다. 별도 정적 호스팅에서는 이 폴더를 루트로 지정하면 됩니다.

독립 실행: 이 폴더에서 `python3 -m http.server 4174 --bind 127.0.0.1`를 실행한 뒤 브라우저로 서버 루트를 엽니다. HTML 파일을 직접 더블클릭하면 브라우저의 로컬 JSON 접근 제한으로 시 본문을 불러오지 못할 수 있습니다.

공개 홈페이지: https://mmwwoo-lab.github.io/myeongdo-1029-1/poetry-book/

## 시화 삽화

작품별로 꽃·새·동물·곤충·풀·산과 물가의 소재를 연결한 AI 수채화 20종을 `media/poetry-watercolors.png`에 포함했습니다. 삽화는 시 제목이 있는 첫 지면에만 배치합니다. 제목 없이 본문이 이어지는 지면에는 삽화가 없습니다. 그림의 설명은 스크린리더에서 읽을 수 있으며 시 원문은 변경하지 않았습니다. 그림과 글이 겹치지 않도록 실제 화면의 제목과 본문 높이를 측정해 페이지를 구성합니다. 목차 쪽수도 자동으로 맞춰집니다.

각 시의 제목은 본문이 시작하는 첫 지면에만 표시하고, 이어지는 지면에서는 반복하지 않습니다. 이어지는 지면에는 삽화를 제외하고 시 본문과 낭송 플레이어를 표시합니다.

## 앞표지와 뒷표지

작가가 제공한 어릿광대 조형물 그림을 활용해 밝은 천 질감의 앞표지 이미지를 구성했습니다(`media/hardcover-art.png`). 마지막 지면은 짙은 남색 천 질감 뒷표지입니다. 앞뒤 표지는 본문과 다른 테두리·두께·쪽수 처리와 넘김 효과를 사용합니다.

표지 제목은 로컬에 포함한 Nanum Brush Script(나눔손글씨 붓)로 표시합니다. 글꼴의 SIL Open Font License는 `media/fonts/OFL-NanumBrushScript.txt`에 포함되어 있습니다. 외부 글꼴 서버 접속은 필요하지 않습니다.

앞·뒷표지 제목은 붓글씨에 금박 그라데이션과 검은 외곽선을 적용했습니다. 표지 아래 중앙에는 “명도재 제작”을 표시합니다.

처음 펼침면은 1쪽 앞표지, 2쪽 노래 영상 소개 순서입니다. 모바일에서는 표지가 먼저 표시됩니다.

## 페이지별 한국어 낭송

38편의 전체 낭송 MP3는 `media/recitals/`에, 원문 SHA-256과 행별 재생 시간 정보는 `recitals.json`에 포함했습니다. eSpeak NG 1.52 한국어 기본 합성음으로 제작했으며 시인 육성이 아닙니다. 각 시 본문 지면의 플레이어는 해당 페이지에 보이는 구절을 재생하고 구간 끝에서 멈춥니다. 전체 시 MP3 다운로드 링크도 제공합니다. 페이지를 넘기거나 다른 미디어를 재생하면 기존 낭송은 멈춥니다.

브라우저 기기 음성 읽기가 아닌 실제 MP3 파일입니다. 자동 재생하지 않습니다. 구간 이동에는 HTTP 바이트 범위 요청을 지원하는 서버가 필요하며 공개 GitHub Pages에서 지원합니다. Python 기본 `http.server`에서는 파일 재생은 되지만 특정 구간으로 이동하는 기능이 제한될 수 있습니다.
